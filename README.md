# Aplicación de Cine

Ejercicio progresivo de PAFW.

## Backend
Express + Prisma + SQLite (api-cine/)

## Frontend
React + Vite (cine-frontend/)

## Desarrollo local
- Backend: copiar `.env.example` a `.env` y ejecutar `npm run dev`
- Frontend: copiar `.env.example` a `.env` y ejecutar `npm run dev`
